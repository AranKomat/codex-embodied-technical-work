# R1 Frozen-Program Generalization Status

The corrected Astra server-repair program is now preserved as a frozen artifact
under `artifacts/server_repair_demo_20260927/frozen_solution/`.

Evidence currently available:

- one fresh integrated replay passed all three stages and the digital healthcheck;
- one three-environment holdout passed physical seating, gripper release, and
  healthcheck in every environment;
- the holdout exercised the same frozen program without additional model calls.

This is evidence of initial robustness, but not yet a complete R1 campaign. The
three environments are replicas in the same fixture family; they do not yet
cover a different faulty component, deliberate staging/layout offsets, or a
different initial robot configuration. Those are the next R1 variants. Keep the
program frozen while evaluating them and report each variant separately.
